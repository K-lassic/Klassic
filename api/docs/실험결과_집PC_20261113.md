## 7. 사용자가 직접 확인해야 하는 것

- 사용자 터미널(Git Bash · PowerShell)에서 운영자 만들기 `-it` 가 되는지, `winpty` 가 필요한지 (E-2). Claude 환경에는 TTY 가 없다.
- 브라우저에서 가입 → 로그인 → 예시 → 결과 → 내려받기 한 번 (구축방법 8절). 이 시험은 API 로만 했고 화면 · 소리는 보지 못했다.
- Funnel 을 켜서 외부 점검(`Secure` 쿠키 포함)을 할지 (E-3).

## 8. 시험 도구 주의 (자동화할 때)

- `docker stats --no-stream` 이 가끔 응답하지 않고 멈췄다 (두 번). 이 때문에 시험 스크립트가 10분 넘게 멈췄다. 메모리는 `docker exec <컨테이너> cat /sys/fs/cgroup/memory.peak` 로 읽는 것이 안전했다.
- PowerShell 의 `Stop-Job` 도 `docker stats` 를 돌리던 job 에서 멈췄다.
- 로그인 세션은 약 7시간 뒤 만료됐다 (`/api/auth/me` 는 로그인 안 한 상태에서도 200 이라서 로그인 확인에 쓸 수 없다). 같은 계정을 새 세션으로 다시 로그인하면 10분 동안 `LOGIN_ALREADY_ACTIVE` (409) 라서, 시험 계정을 새로 가입해서 썼다.

## 9. 실험을 마친 상태

- 시험이 끝난 뒤 서비스를 `docker compose stop` 으로 멈췄다 (컨테이너 · 볼륨 · 이미지는 그대로). 다시 켜는 방법은 남은 작업 문서 2절에 있다.
- 시험으로 만든 계정: 운영자 `exp-op`, 일반 시험 계정 여러 개 (모두 임시). 비밀번호는 이 문서와 저장소에 없다.
- Funnel 꺼짐 · 외부 공개 없음.
