## 4. 문서 수정으로 확인된 것

1. **프런트 Dockerfile**: 공용 폴더 전체를 복사하던 것을 필요한 파일 세 개로 줄였다. 다만 최종 이미지에는 원래도 빌드 결과(`dist`)만 들어가므로, 이미지 크기는 284MB 그대로다. 줄어든 것은 빌드 때 복사하는 양이다.
2. **model-api 베이스 이미지**: `python:3.11-slim-bookworm` 을 설치기와 같은 해시로 고정했다. 해시는 로컬에 있던 이미지의 것과 같았다.
3. **구축 문서**: 환경 변수는 `.env` 한 곳에만 쓰도록 바꿨다. 볼륨 선택(기존 · 새 볼륨), 되돌리기 태그 명령, `winpty` 대안, 프로필 `demo` 단계를 추가했다.

## 5. 아직 확인하지 않은 것

- **새 볼륨으로 처음부터 설치**: 설치기 실행(약 8분, 약 5.6GiB)과 서비스 키 재발급 순서는 이번에 시험하지 않았다.
- **`winpty` 대안**: `docker compose run -it` 가 Git Bash 에서 실패하는지, `winpty` 를 붙이면 되는지 확인하지 않았다.
- **외부 주소 점검**: Funnel 을 켜지 않았다.
- **인식 결과 비교**: 재빌드 전후의 인식 결과가 같은지 확인하지 않았다.
